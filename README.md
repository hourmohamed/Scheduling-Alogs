# 🧠 C++ OOP CPU Scheduling Algorithms

This repository contains **Object-Oriented Programming (OOP)** implementations of several classic and advanced **CPU scheduling algorithms** using **C++**. The project is aimed at helping students and developers understand the logic and behavior of each scheduling method through clear and modular design.

---

## 📌 Implemented Algorithms

- FCFS (First-Come First-Served)
- SPN (Shortest Process Next)
- SRT (Shortest Remaining Time)
- HRRN (Highest Response Ratio Next)
- Round Robin
- Aging
- FB-1 (Feedback Queue – 1 level)
- FB-2i (Feedback Queue – 2 levels with increasing quantum)
